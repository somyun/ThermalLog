# USB 인식 프로토타입 테스트 안내

## 목적

`usb-camera-detection.ahk`는 BOSCH GTC400C의 다음 상황을 검증하기 위한 독립 프로토타입이다.

1. 프로그램 실행 전에 카메라가 연결된 경우
2. 프로그램 실행 후 카메라를 연결한 경우
3. 프로그램 실행 중 카메라를 분리한 경우
4. 동일한 Windows 장치 이벤트가 여러 번 발생한 경우

GTC 제어, 사진 복사 및 일지 작성 기능은 포함하지 않는다. 카메라 드라이브의 파일을 읽기만 하며 수정하거나 삭제하지 않는다.

## 실행

`usb-camera-detection.ahk`를 AutoHotkey v2로 실행한다.

현재 PC의 64비트 실행 경로:

```text
C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe
```

## 테스트 순서

1. 카메라가 연결된 상태에서 프로토타입을 실행한다.
2. `열화상카메라가 연결되었습니다` 메시지박스가 한 번 표시되는지 확인한다.
3. 화면에 `BOSCH GTC400C`, 드라이브 문자, X/Y 이미지 수가 표시되는지 확인한다.
4. 메시지박스를 닫고 카메라 USB를 안전하게 분리한다.
5. 화면이 `열화상카메라 연결 대기 중`으로 바뀌는지 확인한다.
6. 카메라를 다시 연결한다.
7. 연결 메시지박스가 한 번 표시되고 사진 수가 다시 나타나는지 확인한다.
8. `IMAGE 폴더 열기` 버튼이 올바른 카메라 폴더를 여는지 확인한다.

## 감지 기준

1. USB 디스크 모델이 `BOSCH GTC400C`인지 확인
2. USB 저장장치 ID가 `VEN_BOSCH&PROD_GTC400C`인지 확인
3. 현재 할당된 논리 드라이브 탐색
4. 드라이브의 `IMAGE` 폴더 및 X/Y JPG 구조 확인

드라이브 문자와 장치 일련번호는 고정값으로 사용하지 않는다.

## 로그

실행 중 이벤트는 다음 파일에 기록된다.

```text
prototype\logs\usb-detection.log
```
